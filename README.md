Student Marks Manager

Project Description

Student Marks Manager is a simple Python-based project designed to manage student marks and records.

Features

- Add student records
- View all student records
- Calculate class average
- Find the topper
- Exit the program
- Validate marks between 0 and 100

Technologies Used

- Python

Python Concepts Used

- Variables
- Lists
- Input and Output
- If-Else Conditions
- While Loop
- For Loop
- Type Conversion

How to Run

1. Download the "student_marks_manager.py" file.
2. Install Python on your computer.
3. Open the terminal.
4. Run the following command:

"python student_marks_manager.py"
